### >Technical Overview
- **Architecture:** Static HTML5 / Modern CSS / Plain JavaScript (ES6+)
- **Dynamic Features:** Custom Markdown Parser, JSON-driven project grids, client-side i18n (PT/EN)
- **Aesthetic:** Monochromatic brutalist terminal layout, ASCII artwork framing (My Inspirations: CDDA, Dwarf Fortress and Brogue/Rogue)
